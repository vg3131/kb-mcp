# Worx+ Knowledge Base

The Worx+ TechTalk knowledge base for concrete polishing, as markdown
(`mcp-server/worx-techtalk-markdown-kb/`), served two ways:

- **MCP server** (`mcp-server/`): gives Claude hybrid semantic + keyword
  search over the knowledge base and product catalogue, backed by MongoDB
  Atlas. See [`mcp-server/README.md`](mcp-server/README.md).
- **Docs site** (`mkdocs.yml`): a browsable MkDocs Material site built from
  the same markdown.
