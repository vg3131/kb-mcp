# Claude / AI Upload Guide

1. `consolidated/gk-series.md`
2. `consolidated/techtalk-knowledge-cards.md`
3. `consolidated/application-guides.md`

6. `consolidated/video-index.md`

Why this order works:

- The GK Series file gives the AI the highest-value machine reference.
- The knowledge cards provide the practical TechTalk answers.
- The application and process guides give step-by-step field workflow.
- The presenter and video indexes help trace where information came from.
- The catalogue summary gives product/product-category awareness without overwhelming the model.

Use the full `catalogue/` folder only when you specifically need product-code and price lookups.
