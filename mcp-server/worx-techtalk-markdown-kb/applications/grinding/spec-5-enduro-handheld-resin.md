# Spec 5 Enduro Handheld Resin

The Spec 5 Enduro is the extended-lifetime version of the Spec 5 handheld resin. Mechanical mount (no velcro), rigid backing, higher surface area for longer life and more even scratch profile. Designed for contractors who want Spec 5 control but need greater tool longevity — particularly on larger edge runs.

## Tag

Hand Grinder · Resin

## Steps

### Step 1: Mount to hand grinder

Mechanical mount — no velcro attachment. Extremely well-balanced, positive attachment to the tool. More durable in demanding conditions than velcro-backed pads.

### Step 2: Choose Enduro vs original Spec 5

If speed is the priority — use the original Spec 5. If longevity and consistency is the priority (larger jobs, longer edge runs) — use the Enduro. They complement each other, not replace.

### Step 3: Work edge to body grit match

Always match the Spec 5 Enduro grit to the grit being run on the body machine at each stage. This is non-negotiable for a seamless edge-to-body blend.

### Step 4: Use the square edge advantage

The Enduro has a crisp square edge profile right to the outer rim — allows getting hard up against a wall with maximum coverage. No compromising on edge proximity.

## Field Tips

- Higher surface area = longer lifetime, slightly more even scratch profile, easier to control for less experienced operators.
- Open segment pattern still clears densifier and dust effectively — same clearance benefit as the original Spec 5.
- The Enduro was built for the part of the market that loves the Spec 5 feel but needs more from the tool across longer work runs.
