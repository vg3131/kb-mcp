# Crack Filling vs Crack Repairing: Never Use the Word Repair

## Quick Answer

In the polished concrete industry, you never 'repair' a crack — you 'fill' it. The reason is legal and practical: if you call it a repair, you own it. If it cracks again (which it might, since shrinkage continues for 18 months), you are liable. Fill it, document it, and move on. Crack types vary: surface crazing, structural shrinkage, movement joints. Each requires a different approach.

## Source Quote

> If you use the word repair, you own it. We fill cracks. Always. If it cracks again — and it might — that's not your repair failing.
