# Floor Protection Changes Concrete Colour

## Quick Answer

Any cover that restricts moisture evaporation unevenly will cause colour variation. Polythene, Gorilla Board, hessian — all problematic. Calico painter's drop sheets (short-term only) are the best option found so far.

## Source Quote

> Concrete is very sensitive to moisture loss rate. If you cover it, you will see colour change on every lap.
