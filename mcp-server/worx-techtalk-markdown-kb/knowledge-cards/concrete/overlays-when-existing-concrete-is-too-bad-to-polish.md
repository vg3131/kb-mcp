# Overlays: When Existing Concrete Is Too Bad to Polish

## Quick Answer

A polished concrete overlay is a cementitious veneer product (with or without aggregate) poured over existing concrete to create a new polishable surface. Installed at 15-16mm, finished at 12mm — same profile as tiles. Best uses: existing slabs with too many defects, contaminants, or coatings; spaces where exposed aggregate aggregate profile is desired; heritage buildings where the existing slab must be preserved.

## Source Quote

> An overlay is a levelling compound modified to be the finished product. Really attractive when you've got existing premises with undesirable concrete.
