# Boney Floors: Extra Densifier, Extra Patience

## Quick Answer

Boney (porous, soft) slabs need significantly more densifier than well-poured concrete. The identification process takes longer. Start with assessing the material — if it looks boney and the slab is soft, plan for extra chemical application and more careful manufacturing on site. Rushing a boney floor guarantees a poor result.
