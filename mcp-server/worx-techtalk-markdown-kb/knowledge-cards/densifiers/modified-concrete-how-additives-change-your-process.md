# Modified Concrete: How Additives Change Your Process

## Quick Answer

Concrete plants are increasingly adding polymers, fibres, shrinkage reducers, and other admixtures. These modify porosity, surface hardness and how densifier absorbs. A slab that looks normal can absorb differently because of invisible additives — densifier sits on top instead of penetrating. If you start going backwards at 50 resin, go back to check densifier absorption before blaming the tool.

## Source Quote

> Modern concrete has a lot of juice in it from the plants. It affects us contractors right through the polishing stage — changes process, changes everything.
