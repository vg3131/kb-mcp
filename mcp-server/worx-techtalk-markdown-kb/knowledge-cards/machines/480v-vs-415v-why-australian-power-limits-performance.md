# 480V vs 415V: Why Australian Power Limits Performance

## Quick Answer

Machines designed for 480V perform noticeably better overseas. Australian 415V power reduces available torque to the diamond. Cleaner, higher voltage = better ground contact. This is a key reason the 690 underperforms its spec in Australia.

## Source Quote

> These machines run better on 480 volts. The cleaner the power, the better it puts it to the ground.
