# 830 vs 690: The Horsepower Gap

## Quick Answer

The 830 has more HP and new-gen electronic drives — a genuine upgrade. The 690 carries more weight but the same HP as the old 680, with bigger discs requiring more torque. On Australian 415V power it's underpowered. Leave weight kits off the 690; run full sets of doubles at higher RPM instead.

## Source Quote

> More weight, same horsepower, bigger discs — you're running out of horses.
