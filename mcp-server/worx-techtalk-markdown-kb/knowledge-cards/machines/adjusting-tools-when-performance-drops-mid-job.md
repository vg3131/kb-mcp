# Adjusting Tools When Performance Drops Mid-Job

## Quick Answer

When a tool stops performing mid-project — especially in regional areas where you can't get to a supplier — the troubleshooting sequence is: (1) check if it's a bond issue vs. a concrete hardness issue, (2) try a dressing block to re-expose diamonds on resins, (3) on metals, check if you need to add water or CFQ, (4) review your traverse speed and RPM before assuming the tool is dead. A soft-bond metal on hard concrete will die fast — but so will a hard-bond on soft concrete through loading.

## Source Quote

> For a regional customer, the van or warehouse isn't just around the corner. So before you give up on the tool, go through everything first.
