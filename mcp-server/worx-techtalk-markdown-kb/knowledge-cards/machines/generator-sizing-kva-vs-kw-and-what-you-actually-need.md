# Generator Sizing: KVA vs KW and What You Actually Need

## Quick Answer

KVA is apparent power, KW is actual usable power. Most generators run at roughly 0.8 power factor, so a 20KVA generator delivers around 16KW. A 830 three-phase machine draws around 11KW at full load — you need at least a 20KVA generator to run it safely, leaving headroom for startup surge. Going undersized causes voltage drop, poor torque, and overheating.
