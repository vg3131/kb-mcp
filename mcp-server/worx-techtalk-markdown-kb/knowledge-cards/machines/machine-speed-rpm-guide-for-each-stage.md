# Machine Speed: RPM Guide for Each Stage

## Quick Answer

Speed is determined by what you're trying to achieve at each stage — not a fixed number. Metal stage: RPM depends on the hardness of the concrete and tool selection. Coarser metals (6–30 grit) on soft concrete may need less RPM than on hard. Resins: 700–1000 RPM is a good starting point for 50-grit. As you move higher in grit, lower RPM generates less heat. The operator is as important as the setting — slow your traverse speed first before changing RPM when a tool isn't performing.

## Source Quote

> When it comes to speeds, it's really determined by what's happening on site, what you're trying to achieve, what stage you're at. There's no magic number.
