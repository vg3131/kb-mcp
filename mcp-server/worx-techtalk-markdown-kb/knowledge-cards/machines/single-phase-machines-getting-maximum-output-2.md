# Single Phase Machines: Getting Maximum Output

## Quick Answer

For contractors committed to single-phase lightweight machines, the key is tooling selection and RPM management. Run smaller diamond counts for higher point pressure. Don't add weight kits beyond what the motor was designed for. Keep RPMs at the higher end of the tool's range. Single phase machines have been in the market for decades because they work — but you need to know their ceiling and work within it, not against it.
