# Single Phase Machines: Getting Maximum Output

## Quick Answer

Single phase 530s and similar machines have been in the market for decades for a reason. Key tips for maximising output: run smaller segment counts to increase point pressure, keep RPM high, don't overload with weight kits the motor wasn't designed for. For getting started in the industry they're a legitimate entry point — but know their ceiling.

## Source Quote

> Single phase machines — they've been around for a long time for a good reason. Know their limits but work within them properly.
