# Chemical Compatibility: Not All Products Work Together

## Quick Answer

Chemical products in the polishing process interact with each other — grouting compounds, densifiers, and sealers all need to be compatible. Running competitor products in between Worx+ steps can create reactions. If you get a call that a floor looks wrong after the third step, the first question should be: what was applied at each stage and by whom?

## Source Quote

> Chemicals need to work together. If there's two good things and someone says combine them — don't. Compatibility first, results second.
