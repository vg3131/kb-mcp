# Dedicated Plates from 120 Grit Onwards

## Quick Answer

30s and 50s wear by design — plate swapping is fine. From 120 onwards, keep resin tools on dedicated plates. Un-bedded tools produce visibly different profiles with lighter edges and inconsistent scratch patterns.

## Source Quote

> From 120s onwards, dedicated plates. Non-negotiable.
