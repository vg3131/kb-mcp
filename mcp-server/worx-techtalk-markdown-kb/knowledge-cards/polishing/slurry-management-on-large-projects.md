# Slurry Management on Large Projects

## Quick Answer

Poor slurry control on 8,000+ sqm wet-cut projects kills productivity. Plan slurry collection before the project starts — 40-gallon drums, settlement, truck pickup. If this isn't pre-planned, the entire crew stops producing.

## Source Quote

> The biggest thing we worked out early was slurry control. If you're not controlling that slurry it's just a mess.
