# The MSY Combo for Four-Head Machines

## Quick Answer

For HTC-style four-headed machines that can't change direction: combine soft-bond 30 single rocks with double medium-30 zigzags per head. The zigzag provides aggression via geometry; the soft single provides clean scratch pattern. Game-changing for first-cut productivity.

## Source Quote

> Soft 30 single rock, double medium 30 zigzag — increased point pressure, nice and aggressive.
