# Three Types of Sealers: Know What You're Applying

## Quick Answer

The three categories are: (1) Impregnating/penetrating sealers — absorb into the concrete and chemically alter surface tension (e.g. Totally Defend). (2) Penetrating reactive sealers — penetrate and react with the concrete (e.g. Worx+ Pen-X). (3) Topical/coating sealers — sit on top and form a film. Each has different applications, maintenance needs, and compatibility with polished concrete. Applying the wrong type for the use case causes failures.

## Source Quote

> Three main sealer types — impregnating, penetrating, topical. Each has a completely different job. Know the difference before you reach for the tin.
