# External Coaching Lands Differently

## Quick Answer

Employees receive instruction from an external coach very differently than from the boss. The authority dynamic creates resistance internally. An outsider saying 'have you thought about this?' gets curiosity, not defensiveness.

## Source Quote

> Coming from external can be received very differently. The relationship's different.
