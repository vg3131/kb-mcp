# Tempo Pads: Which Side Goes Down

## Quick Answer

A common early question: Tempo pads (diamond impregnated pads) have a colour for a reason — that colour side goes down. The pad is designed so the diamond media on the coloured face makes contact with the floor. Running them upside-down does nothing and wastes the pad. This sounds obvious once you know it — but it's one of the most common calls in the early days of using them.

## Source Quote

> Tempo pads — which way? They have a colour for a reason. The coloured side goes down. That's where the diamond media is.
