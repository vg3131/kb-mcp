# 55T Vacuum: Getting the Most From It

## Quick Answer

The 55T three-phase vacuum is the most-called-about product in the Worx+ range. Key tips from Hayden: empty filter bags regularly — don't wait for suction to drop before changing. Check the filter gasket seal after any bag change. When running wet, make sure the float valve is working correctly to prevent motor flood. A 55T running at 80% suction is silently reducing your machine's performance and sending fine dust into the drivetrain.

## Source Quote

> The main problem with the 55T is it really sucks — which is awesome. When it stops sucking properly, that's when we get the calls.
