# Why Attend a Seminar Even When Experienced?

## Quick Answer

The most experienced contractors in the industry still attend seminars — not because they don't know the basics but because the concrete they're working with keeps changing. New supplementary materials, new mix designs, new sealer chemistries, new machine capabilities. Every seminar surfaces at least one thing that changes the way an experienced operator thinks about a step they've done a thousand times.

## Source Quote

> I always pick up a few things here and there that I never thought of — and I've been doing this for a long time. So does everyone else in the room.
