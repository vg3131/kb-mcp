# Normal vs Special Class Concrete

## Quick Answer

Normal Class (N) only has to meet strength. The supplier can use whatever mix they like. Special Class (S) involves the technical department. For polished slabs, specify Special Class at 40 MPA — but builders rarely request it.

## Source Quote

> Normal class — the supplier is at liberty to put whatever they like in it, as long as they make strength.
