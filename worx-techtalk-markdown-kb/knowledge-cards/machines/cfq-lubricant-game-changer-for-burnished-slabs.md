# CFQ Lubricant: Game-Changer for Burnished Slabs

## Quick Answer

CFQ (originally for road saws) enables grinding burnished floors at walking speed with hard-bond diamonds. One set of segments did 8,000+ sqm with 7mm remaining. Spray in front of the machine via backpack sprayer — no water, no sand, no nothing.
