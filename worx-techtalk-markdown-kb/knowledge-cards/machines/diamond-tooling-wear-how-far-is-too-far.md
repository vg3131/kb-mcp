# Diamond Tooling Wear: How Far is Too Far?

## Quick Answer

Optimal tooling performance is when diamonds first come out of the box — fresh, fully dressed. Beyond that, you're extracting value vs. accepting reduced performance. Metal bonds: worn past the optimal point are slower, generate more heat, and leave worse scratch patterns. Resins: glazed resins stop cutting efficiently — redress with a dressing block. The rule is bottom-line economics: if a worn tool is costing you more in time than a new tool would cost, change it.

## Source Quote

> Optimal is when the diamonds come out of the box. After that, the question is — how much value can I extract before the bottom line suffers?
