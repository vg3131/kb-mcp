# Spring Heads vs Demo Heads: The Myth

## Quick Answer

Spring heads (older design, spring steel) are commonly believed to be 'better for polishing' — this is a myth. Demo heads actually offer MORE flexibility than spring heads despite their name suggesting they're only for demolition. Spring heads are more limited in flex and should be phased out. Tim Van der Veen (the inventor) apologised for the spring head in Ep 32.

## Source Quote

> I can't do this anymore talking about spring heads being better for polishing. Demo heads have more flex — it's very misleading.
