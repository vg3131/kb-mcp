# Edge Grouting: Match the Machine

## Quick Answer

Edge grouting process should replicate whatever the body machine is doing. Bring edges to saturation with water first, apply grout, and keep working it. The most common edge mistake is skipping the pre-wet step — grout sits on top instead of penetrating. Don't over-complicate it. The Worx+ RoboEdge is an automatic edging machine that removes the manual effort and produces consistent results.
