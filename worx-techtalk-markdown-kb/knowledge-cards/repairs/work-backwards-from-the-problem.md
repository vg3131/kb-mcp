# Work Backwards From the Problem

## Quick Answer

At 2am with scratches in the floor, the instinct is to keep throwing tools at it. The proven approach: stop, call someone trusted, clarify what was done before, identify where the problem started. The resin tool is never the root cause.

## Source Quote

> Zone it in, work all the way back, problem-solve with a clear mind.
