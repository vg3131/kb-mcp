# Scratches Still Visible After Resin Stage

## Quick Answer

If scratches remain visible after the 50 or 100 resin stage, the previous metal bond grit was not fully removed before progressing. Common causes: moving too fast, skipping grits, worn tool not changed, insufficient passes, or densifier applied before the metal stage was complete. Always do a visual and tactile scratch check before moving forward.

## Source Quote

> You haven't removed the previous grit. Going backwards costs more time than doing it right the first time.
