# The Worx+ Process: Cut Sikk for Burnished Slabs

## Quick Answer

On burnished or hard-capped slabs where water misting alone is insufficient to get diamonds cutting, apply Cut Sikk via backpack sprayer directly in front of the machine during the 30-grit stage. Cut Sikk is a lubricant that enables hard-bond diamonds to cut through the sealed surface cap — the same chemistry that enabled an entire 8,000 sqm floor using one set of hard segments with 7mm remaining. It replaces the need to run soft bonds on hard surfaces.

## Source Quote

> Mist a little water in front of the machine. Use Cut Sikk if needed on burnished or hard-capped surfaces.
