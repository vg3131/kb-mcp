# GK Series Operation Guide

## Step 1: Start with soft 30 single segments

Use this as the baseline shakedown setup. Singles give maximum point pressure and quickly show how the slab is reacting.

## Step 2: Start light, then load the head

With aggressive tooling, start around positions 8–10. Once stable, progressively move toward position 0 while watching current draw.

## Step 3: Use current draw as the floor feedback

Rising amps means load is increasing. If it spikes, reduce head weight or adjust tooling. If it falls, add weight or increase production speed.

## Step 4: Use the 850’s extra slots for heat control

More segments spread the machine weight across more contact area. This is the 850’s advantage on long commercial runs.

## Step 5: Back off over ridges and soft spots

Shift the chassis back before ridges, joints or soft patches, then reload the head once the machine is stable again.

## Step 6: Recalibrate wheels after hub disconnection

Use the wheel calibration menu to align and lock each wheel correctly before operation.
